## 1. Executive Summary

This plan addresses three interconnected issues with the Harmonia Beaker LLM Agent environment:

1. **Missing `bdikit_context.llm.anyllm` module** in the Apptainer container
2. **Data file accessibility** - the LLM needs to find `dou.csv` in the experiment folder
3. **Output directory management** - results should be saved to experiment-specific folders

---

## 2. Root Cause Analysis

### 2.1 Missing `bdikit_context.llm.anyllm` Module

**Error Observed:**
```
ModuleNotFoundError: No module named 'bdikit_context.llm.anyllm'
```

**Root Cause:**
The current `jupyter.def` Apptainer definition file:
1. Copies `src/bdikit_context/` to `/jupyter/src/bdikit_context/`
2. Installs the package with `pip install --no-build-isolation .`
3. But the `llm/` subdirectory containing `anyllm.py` **is present in the source** but the `any-llm-sdk` dependency is **NOT installed**

The `pyproject.toml` declares `any-llm-sdk` as a dependency:
```toml
dependencies = [
  "any-llm-sdk",
]
```

However, `any-llm-sdk` requires:
- A local installation from `/hpc/compgen/projects/llm_GEO_project/any-llm`
- Additional provider-specific dependencies (e.g., `ollama>=0.5.1` for Ollama support)

**The container build does not have access to the local any-llm repository** and the package is not available on PyPI under the expected name with the correct version.

### 2.2 Data File Accessibility

**Current Situation:**
- `dou.csv` is copied into the container at build time: `/jupyter/dou.csv`
- The experiment config specifies: `working_directory: /hpc/compgen/projects/llm_GEO_project/harmonia_metadata_agent/raw/datasets_harmonia/one_metadata_table_gdc_schema/data`
- The `exec_apptainer_harmonia.sh` uses `--bind .:/jupyter` which binds the **current working directory** to `/jupyter`

**Problem:**
- If the user runs from the harmonia directory, `dou.csv` is available at `/jupyter/dou.csv`
- But the config expects it at a specific HPC path that needs to be bind-mounted

### 2.3 Output Directory Management

**Current Situation:**
- Results go to `/hpc/compgen/projects/llm_GEO_project/harmonia_metadata_agent/analysis/dstoker/harmonia/results/`
- The automation code creates timestamped directories like `dou_gdc_manual_anyllm-ollama_devstral-small_20260127_151627`

**Problem:**
- The container needs write access to the results directory
- The bind mount configuration may not include the results directory

## 5. Detailed Implementation Steps

### Step 1: Create harmonia_beaker_LLM_agent_environment_apptainer.def

```apptainer
Bootstrap: docker
From: python:3.11  # Upgraded from 3.10 for any-llm-sdk compatibility

%files
    # Copy source files
    src /jupyter/src
    pyproject.toml /jupyter/pyproject.toml
    README.md /jupyter/README.md
    # Note: dou.csv will be accessed via bind mount, not copied

%post
    # Use /var/tmp for builds
    export TMPDIR=/var/tmp
    export UV_CACHE_DIR=/var/tmp/uv_cache
    export PIP_CACHE_DIR=/var/tmp/pip_cache
    mkdir -p /var/tmp/uv_cache /var/tmp/pip_cache

    useradd -m jupyter
    apt update && apt install -y lsof git

    # Install uv and hatch
    pip install --no-cache-dir uv
    TMPDIR=/var/tmp uv pip install --system --no-cache hatch hatchling

    # Install beaker_kernel
    TMPDIR=/var/tmp uv pip install --system --no-cache "beaker_kernel>=1.14.0"

    # Install any-llm-sdk with ollama provider
    # Using the GitHub repository since local path isn't available at build time
    TMPDIR=/var/tmp uv pip install --system --no-cache "any-llm-sdk[ollama] @ git+https://github.com/mozilla-ai/any-llm.git"

    # Set ownership
    chown -R 1000:1000 /jupyter

    # Build and install bdikit_context
    cd /jupyter
    TMPDIR=/var/tmp pip install --no-cache-dir --no-build-isolation .

    # Verify the installation
    python3 -c "from bdikit_context.llm.anyllm import AnyLLMModel; print('AnyLLMModel imported successfully')"
    python3 -c "from any_llm import AnyLLM; print('any_llm imported successfully')"

    # Create legacy context mapping
    mkdir -p /usr/local/share/beaker/contexts
    cat > /usr/local/share/beaker/contexts/bdikit_context.json << 'EOF'
{
    "slug": "bdikit_context",
    "package": "bdikit_context.context",
    "class_name": "BDIKitContext"
}
EOF

    # Cleanup
    rm -rf /var/tmp/uv_cache /var/tmp/pip_cache

%environment
    export PYTHONPATH=/jupyter

%runscript
    cd /jupyter
    exec beaker dev watch --ip 0.0.0.0
```
