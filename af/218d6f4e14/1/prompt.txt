   - **Run ID System**: 8-char hex IDs linking logs to results
   - **flock-based concurrency**: For Phoenix server singleton management
   - **screen sessions**: For persistent Phoenix server processes
   - **Pre-commit hooks**: ruff (Python linting), shellcheck (shell script linting), yamllint
