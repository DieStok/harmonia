- **Previous:** `model: olmo-3:latest`
- **Fixed:** `model: olmo-3.1:32b` (has tool support)

### Issue 3: Output Files Not in Results Folder
- **Previous:** Files saved to `/jupyter` (container working directory)
- **Fixed:** Working directory changed to results folder before experiment starts

### Issue 4: PyTorch 2.6 Compatibility with BDI-Kit (BLOCKING)

- **Error:** `UnpicklingError: Weights only load failed` when using `ct_learning` method
- **Cause:** PyTorch 2.6 changed `torch.load` default from `weights_only=False` to `weights_only=True`
- **Impact:** BDI-Kit's contrastive learning model checkpoint uses `argparse.Namespace` which is blocked
- **Status:** NEEDS FIX - Requires container rebuild with patch

**Fix Options:**

1. **Patch BDI-Kit in container** - Add `weights_only=False` to torch.load call in `cl_api.py`
2. **Downgrade PyTorch** - Use PyTorch < 2.6 in container
3. **Use different method** - Change from `ct_learning` to `similarity` or `coma` method

**Temporary Workaround:**

Update experiment configs to use a different matching method:

```yaml
# Instead of:
method: ct_learning
# Use:
method: similarity  # or 'coma', 'magneto', etc.
```
